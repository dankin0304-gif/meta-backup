# Altare free cloud server

Goal ID: goal_a12fdb526a78
Goal slug: altare-free-cloud-server

## Description
Claim and start a free Altare cloud server for Kin, using the Always Free pool with no card attached. The Debian 13 server main in Singapore is created with 6 GiB memory, 1.5 CPU and 10 GiB disk, and SSH access is saved in the vault. Starting it still needs a Discord account link, and the Singapore node is congested, so the Discord appeal and a timed recheck are the open steps.
